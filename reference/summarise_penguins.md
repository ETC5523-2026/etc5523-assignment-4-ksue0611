# Summarise Penguin Body Measurements

Calculate average body mass and flipper length for selected penguin
species.

## Usage

``` r
summarise_penguins(data, species)
```

## Arguments

- data:

  A data frame containing penguin measurements.

- species:

  A character vector of species to include.

## Value

A data frame with the number of penguins, mean body mass and mean
flipper length by species.
