# Cleaned Penguins Data

Body measurements of Adelie, Chinstrap and Gentoo penguins from three
differnet islands.

## Usage

``` r
penguins_clean
```

## Format

A data frame with 342 rows and 6 variables:

- species:

  Penguin species.

- island:

  Island where the penguin was observed.

- bill_length_mm:

  Bill length in millimetres.

- bill_depth_mm:

  Bill depth in millimetres.

- flipper_length_mm:

  Flipper length in millimetres.

- body_mass_g:

  Body mass in grams.

## Source

Penguins dataset from the palmerpenguins R package (CC0 licence).
